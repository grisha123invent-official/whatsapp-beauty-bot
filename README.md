# WhatsApp GPT Бот для бизнеса и салонов красоты

## 🚀 Ваш личный AI-менеджер в WhatsApp!

**Автоматизируйте приём заявок, консультации и ответы на частые вопросы прямо в WhatsApp — 24/7, без выходных!**

### Что умеет бот?
- 💬 Ведёт диалог с клиентом в WhatsApp на базе GPT (ChatGPT)
- 🤖 Сам задаёт вопросы, собирает имя, телефон, услугу, пожелания и вопросы клиента
- 📩 Автоматически отправляет заявки на ваш email
- 🕒 Отвечает на вопросы о часах работы, акциях, стоимости услуг — быстро и без ошибок
- 🏆 Работает без вашего участия: не пропустит ни одного клиента, не забудет задать важный вопрос
- 🔒 Все данные клиентов защищены, а вы получаете заявки мгновенно

- Салоны красоты, барбершопы, студии маникюра

## Как это работает?
1. Клиент пишет вам в WhatsApp
2. Бот сам приветствует, уточняет имя, телефон, услугу, вопросы
3. Вся переписка ведётся на естественном русском языке — клиенту комфортно, как с живым менеджером
4. После сбора всех данных бот отправляет заявку на ваш email
5. Вы получаете готовую заявку и можете сразу связаться с клиентом

## Быстрый старт

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <repo-url>
   cd whatsapp_bot
   ```
2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # или .venv\Scripts\activate для Windows
   ```
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Создайте файл .env и укажите переменные:**
   ```env
   OPENAI_API_KEY=sk-...ваш-ключ...
   EMAIL_USER=your_email@gmail.com
   EMAIL_PASS=your_email_password_or_app_password
   EMAIL_TO=receiver_email@example.com
   ```
5. **Запустите бота:**
   ```bash
   python main.py
   ```

## Технические детали
- Работает через WhatsApp Web (webwhatsapi) — потребуется отсканировать QR-код при первом запуске
- Использует OpenAI GPT для диалогов (нужен API-ключ)
- Email отправляется через SMTP (Gmail или другой сервис)
- Все настройки — через .env файл
